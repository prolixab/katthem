# Versionsanteckning – version 0.6.055

Datorns sidomeny ligger fast när huvudinnehållet rullas. På mobil ligger logotyp och menyknapp kvar högst upp. Långa menyer rullas internt så att alla alternativ kan nås utan att knappen försvinner. Manualen och README är uppdaterade.

Verifierat i webbläsare vid sidans slut på dator, mobil samt låg mobilskärm med lång administratörsmeny. Riktat gränssnittstest passerar.
