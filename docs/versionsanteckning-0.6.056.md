# Versionsanteckning – version 0.6.056

Admin och superadmin kan ta bort enstaka checklistpunkter. Minst en fråga måste finnas kvar i varje avsnitt; sista frågans borttagningsknapp är spärrad och inget avsnitt tas bort automatiskt. Ändringarna genomförs först vid sparning. Borttagna punkter slutar räknas som krav även i tidigare revisioner och övriga kryss bevaras. Valet om vilka som omfattas av nya punkter fungerar som tidigare.

Volontärprofilen har Engagemang och status med Ändra status / pausa. SA kan uppdatera och pausa även andra admins och styrelsemedlemmar. Vanliga admins får inte utökad behörighet. Paus kräver uppföljningsdatum och hantering av kommande pass, men behåller konto, roll och styrelseuppdrag.

Pausade, inaktiva och avslutade kontaktpersoner döljs från volontärernas kontaktlistor, även med styrelseuppdrag eller adminroll. Den privata profilen finns kvar för admin/SA och visas åter som kontaktperson efter återaktivering när övriga villkor uppfylls. Statusen gäller valt katthem.

Manualerna och README är uppdaterade, inklusive ett särskilt avsnitt om personlig Messenger-profil med länkar, sparning och felsökning. Ändringarna i 0.6.054–0.6.055 om whiteboardöverlämning och synlig meny har bevarats.

Ingen uppdateringsnyhet publiceras denna gång enligt användarens uttryckliga önskemål.
