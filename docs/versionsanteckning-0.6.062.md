# Versionsanteckning – 0.6.062

CSV-importen känner igen katthem, inklusive Jönköping som Huskvarna. Admin importerar till valt hem. Global superadmin kan fördela en fil mellan hem. Okända eller saknade hem måste väljas eller hoppas över före import. Förhandsgranskningen visar mål och orsaker till överhoppade rader. Delresultat redovisas per hem och befintliga konton hoppas över vid återförsök. Manual, README och två onboardingguider är uppdaterade.

Verifiering: samtliga 152 tester passerade före commit, inklusive behörigheter, mappning, dubbla e-postadresser, återförsök och delvis misslyckad import.

## Utkast till uppdateringsnyhet

Rubrik: Uppdatering 0.6.062 – import till rätt katthem

CSV-importen kan nu läsa vilket katthem varje volontär tillhör. Admin importerar till valt katthem och superadmin kan fördela en fil mellan flera hem. Förhandsgranskningen visar vart varje person hamnar och ber dig kontrollera saknade eller okända katthem. Manualen är uppdaterad.

Publiceras en gång för samtliga katthem efter lyckad push. Sluttid är verklig pushtid plus exakt 72 timmar. Publicera endast med autentiserad driftåtkomst och kontrollera först att nyheten inte redan finns.
