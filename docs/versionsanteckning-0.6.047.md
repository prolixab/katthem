# Versionsanteckning – version 0.6.047

Inloggade volontärer ser nu bokade personers namn på passkorten i veckokalendern, i listvyn och när ett pass öppnas. Namnregeln är samma som på schemavisningssidan: förnamn och endast de efternamnsbokstäver som behövs när flera har samma förnamn.

Admin och superadmin behåller fullständiga namn och bokningshantering. Andras boknings-id, användar-id och e-post lämnas inte ut till volontärvyn. Inställda pass visar ingen deltagarlista för volontärer. Namnen uppdateras med schemat efter bokning och avbokning.

Manualen och README är uppdaterade. Uppdateringsnyheten publiceras för alla katthem med sluttid exakt 72 timmar efter lyckad push.

## Utkast till uppdateringsnyhet

Rubrik: Uppdatering 0.6.047 – se vilka som bokat pass

Nu ser även inloggade volontärer vilka som har bokat sig på passen. Namnen visas i veckokalendern, listvyn och när du öppnar ett pass. Precis som på schemavisningssidan visas förnamn, med efternamnsbokstäver när flera har samma förnamn. Manualen är uppdaterad.
