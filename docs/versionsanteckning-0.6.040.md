# Versionsanteckning – version 0.6.040

Kontaktpersoner visas i kompakta kort med initialer, uppdrag och samlade kontaktvägar. Två kolumner på större skärmar och en på mobil. Ändra telefon finns kvar för administratörer.

Admin och superadmin kan ange Kontaktansvar i volontärprofilen: Jönköping / Huskvarna, Värnamo eller Båda katthemmen. Fältet börjar tomt och är separat från arbetsplats, roll och katthemsåtkomst. Kontaktpersoner för valt katthem visas först; övriga tillgängliga kontakter finns kvar. Kontaktansvar följer befintlig profilsynkronisering med skydd för lokala ändringar.

Manualerna för alla roller och README är uppdaterade. Verifierat med 114 automatiska tester samt lokal kontroll av profiländring och kontaktkort på dator och mobil.

Gemensam uppdateringsnyhet publiceras med sluttid exakt 72 timmar efter lyckad push. Verklig pushtid registreras efter lyckad push.
