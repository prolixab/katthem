# Versionsanteckning – version 0.6.049

Manuell grönmarkering räknas åter in i grönstatusen. För volontärer krävs komplett introduktionschecklista samt antingen en sparad manuell markering eller minst tio genomförda pass. Tidigare sparade manuella markeringar börjar gälla när checklistan är klar utan att personen behöver markeras igen. Admin och superadmin är fortsatt gröna genom sin roll.

Alla inloggade kan öppna sin egen checklista via Mitt konto → Min introduktionschecklista eller Praktisk information → Introduktion och stöd, även efter godkänd introduktion. Detta omfattar styrelse, admin och superadmin. Var och en kryssar i sina egna punkter. Admins läsvy över andras framsteg är fortsatt skrivskyddad.

För administratörskonton ersätts den tidigare låsta rutan för volontärgodkännande av en förklaring: grönstatus genom rollen betyder inte att checklistan är besvarad. Volontärernas godkännande hanteras som tidigare.

Manualerna och README är uppdaterade. Uppdateringsnyheten publiceras för alla katthem med sluttid exakt 72 timmar efter lyckad push.

## Utkast till uppdateringsnyhet

Rubrik: Uppdatering 0.6.049 – egen checklista och rättad grönmarkering

Manuell grönmarkering fungerar nu som avsett när hela introduktionschecklistan är klar. Tidigare sparade markeringar behöver inte göras om. Alla, även styrelse, admin och superadmin, kan öppna sin egen checklista via Mitt konto → Min introduktionschecklista. För administratörskonton förklarar profilen skillnaden mellan grönstatus genom rollen och besvarade checklistpunkter. Manualen är uppdaterad.
