# Versionsanteckning – version 0.6.045

Välkomstmejlet innehåller Ditt nästa steg med uppmaning att börja introduktionsstegen på startsidan, läsa rutiner och genomföra checklistan. Ett tillfälligt tillägg förklarar varför redan erfarna volontärer också går igenom portalens introduktion och att admin kan bekräfta tidigare praktisk introduktion.

Tillägget utelämnas automatiskt från utskick från 1 januari 2027 kl. 00.00 Europe/Stockholm (31 december 2026 kl. 23.00 UTC). Datum kontrolleras vid utskick, även för köade mejl och nya inbjudningar. Vanlig introduktionsinformation och befintliga krav finns kvar. Redan skickade mejl och lösenordslänkarnas giltighet ändras inte.

Manualerna och README är uppdaterade. Tidigare ändringar från version 0.6.042–0.6.044 har bevarats.

Uppdateringsnyhet publiceras gemensamt med sluttid exakt 72 timmar efter lyckad push. Verklig pushtid registreras efter att pushen lyckats.
