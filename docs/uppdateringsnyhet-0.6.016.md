# Utkast – version 0.6.016

Inte publicerad. Sluttid = faktisk lyckad pushtid + 72 timmar.

Rubrik: En enklare start för nya volontärer – version 0.6.016

Nya volontärer kan boka sina första tre introduktionspass efter att ha bekräftat aktuella rutiner. Checklistan ska fortfarande fyllas i helt. När den är klar får alla admins i katthemmet en notis på startsidan och i Administration om att personen väntar på slutligt godkännande. Volontären ser också sin status och hur många egna bokningar som återstår.

Efter tre bokade eller genomförda pass behövs ett slutligt godkännande för att boka fler själv. Avbokade och inställda pass räknas inte. Notisen försvinner när personen godkänts. Manualerna är uppdaterade och volontärmanualen visar bara relevanta instruktioner.
