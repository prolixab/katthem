# Versionsanteckning – version 0.6.046

Volontärlistan för admin och superadmin delas automatiskt upp i bokstavssektioner med svensk sortering, antal personer och snabbnavigering. Sökning och filter uppdaterar sektionerna direkt och tomma sektioner döljs. På mobil kan bokstavsraden rullas i sidled.

Den privata volontärprofilen visar Senast inloggad med datum och klockslag i svensk tid, separat från Senast på plats. Endast lyckad inloggning uppdaterar tiden. Byte av katthem och automatiska uppdateringar ändrar den inte. Registreringen börjar efter publicering; äldre inloggningstider gissas inte. Uppgiften följer med vid kontoflytt och rensas vid gallring.

Användarmanualen och README är uppdaterade. Uppdateringsnyheten publiceras för alla katthem med sluttid exakt 72 timmar efter lyckad push.

## Utkast till uppdateringsnyhet

Rubrik: Uppdatering 0.6.046 – enklare volontäröversikt

Volontärlistan är nu uppdelad i bokstavssektioner med snabbval och antal personer. Sökning och filter fungerar över hela listan. Admin och superadmin kan dessutom se Senast inloggad i volontärprofilen, separat från Senast på plats. Inloggningstiden börjar registreras vid nästa lyckade inloggning efter uppdateringen. Manualen är uppdaterad.
