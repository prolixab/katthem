# Utkast – version 0.6.026

Admin och superadmin kan nu uppdatera städrutinerna som visas på passen: gemensamma dagliga uppgifter och uppgifter per veckodag. Ändringarna gäller det valda katthemmet och visas på passen utan att bokningar påverkas.

Inte publicerad. Publicera en gemensam sammanfattning av samtliga opublicerade ändringar vid lyckad push, med sluttid exakt 72 timmar efter den verkliga pushtidpunkten.
