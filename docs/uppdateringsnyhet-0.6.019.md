# Utkast – version 0.6.019

Inte publicerad. Sluttid = faktisk lyckad pushtid + 72 timmar.

Rubrik: Händelser på Anslagstavlan och nedladdning av säkerhetskopior – version 0.6.019

Händelser samlas nu under Anslagstavla, tillsammans med nyheterna. Där kan du öppna information och boka. Admin kan också skapa och hantera händelser. Händelserna finns kvar i kalendern.

Systemets superadmin kan ladda ner en komplett säkerhetskopia som ZIP under Säkerhetskopiering. Kopian kontrolleras före nedladdning. Manualerna är uppdaterade.
