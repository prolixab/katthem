# Utkast – version 0.6.022

Inte publicerad. Sluttid = faktisk lyckad pushtid + exakt 72 timmar.

Rubrik: Veckoschema på katthemmets skärm – version 0.6.022

Admin kan skapa en separat visningslänk för skärmen på katthemmet. Sidan visar idag och sex dagar framåt med veckonummer och avdelare vid veckobyte och uppdateras automatiskt, med enbart läsåtkomst. Deltagarnamn är valfria. Visningsskärmen kan inte boka pass, ändra uppgifter eller öppna profiler. Admin kan byta eller återkalla länken. Manualen beskriver hur skärmen kopplas på.

Även tidigare lokalt förberedda ändringar ingår: korrekt e-postvisning mellan katthem, ZIP-nedladdning av kopior, händelser på Anslagstavlan och den valbara närvaromodulen, avstängd från början.

När den valbara närvaromodulen är aktiv kan skärmen även visa en QR-kod för frivillig bekräftelse på egen mobil. Skärmen visar inga närvarolistor och får inga skrivrättigheter.

Vid namnvisning visas enbart bokade volontärers förnamn på skärmen.
