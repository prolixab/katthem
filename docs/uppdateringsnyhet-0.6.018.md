# Utkast – version 0.6.018

Inte publicerad. Sluttid = faktisk lyckad pushtid + 72 timmar.

Rubrik: Tydligare bokningshjälp och tryggare drift – version 0.6.018

Om en bokning är stoppad visas nu orsaken och en knapp till nästa steg. Administratörer får en ändringshistorik för viktiga åtgärder. Systemets superadmin kan se status för dagliga säkerhetskopior och köra en återläsningskontroll. Manualerna är uppdaterade. Även möjligheten att byta katthemmets namn från version 0.6.017 ingår i denna uppdatering.
