# Versionsanteckning – version 0.6.060

Rollen Samordnare kan se bemanning och boka eller avboka pågående och kommande arbetspass åt deltagare, även återkommande bokningar. Åldersregeln och skyddet för sista myndiga deltagaren gäller. Samordnaren får bara nödvändiga deltagarnamn och bokningsuppgifter, inte privata profiler eller e-postlistor. Konton, lösenord, roller, introduktionsgodkännanden, rutiner och systeminställningar behåller admin-/SA-skyddet. Rollen ger ingen automatisk grönmarkering. Gemensamma event kräver separat eventansvar.

SA tilldelar rollen i volontärprofilen och kan ge separat samordnaråtkomst i ytterligare katthem. Befintliga extra tilldelningar bevaras vid uppgraderingen. Återkallelse gäller vid nästa serverbegäran. Manual och README är uppdaterade.

Verifiering: 149 tester passerar, inklusive samordnarens tillåtna och nekade API-anrop, rollstyrd meny, åtkomst i två katthem, återkallelse och åldersskydd.

## Utkast till uppdateringsnyhet
Rubrik: Uppdatering 0.6.060 – ny roll: Samordnare

Nu finns rollen Samordnare. SA kan tilldela rollen i volontärprofilen och separat för ytterligare katthem. Samordnare kan se bemanning samt boka och avboka arbetspass åt andra. Åldersreglerna gäller som vanligt. Eventansvar tilldelas separat. Rollen ger ingen automatisk grönmarkering eller tillgång till kontohantering och systeminställningar. Manualen är uppdaterad.

Nyhetens sluttid ska vara exakt 72 timmar efter lyckad push.
