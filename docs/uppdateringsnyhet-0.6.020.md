# Utkast – version 0.6.020

Inte publicerad. Sluttid = faktisk lyckad pushtid + 72 timmar.

Rubrik: Förberedd tillvalsmodul för dagens bemanning – version 0.6.020

En frivillig närvarobekräftelse är nu förberedd som separat modul och är avstängd från början. Superadmin kan aktivera den senare per katthem. Då kan volontärer bekräfta ett eget pass eller en spontan insats. Modulen visar enbart dagens positiva bekräftelser, utan arbetstider, frånvarolistor eller koppling till statistik och godkännanden. Manualen beskriver påkoppling och användning.

Även tidigare förberedda ändringar ingår: superadmin kan ladda ner en verifierad säkerhetskopia som ZIP, och händelser samlas under Anslagstavlan.
