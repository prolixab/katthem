# Utkast – version 0.6.013

Inte publicerad. Sluttid sätts till faktisk lyckad pushtid + 72 timmar.

Rubrik: Nytt i volontärportalen – version 0.6.013

Vi rekommenderar nu högst fem deltagare per pass. Admin kan anpassa antalet under Administration → Bokningsrekommendation för sitt katthem. Fler kan fortfarande boka efter extra bekräftelse. Befintliga bokningar ligger kvar. Rekommendationen gäller även återkommande bokningar och när admin bokar åt andra. Manualen beskriver inställningen.

Uppdateringen innehåller också mobil dagvy, introduktionsöversikt, stabilare schemauppdatering och lösenordsåterställning till rätt katthem från den ännu opublicerade versionen 0.6.012. Publicera en gemensam sammanfattning vid samma push så att nyheterna inte dubbleras.
