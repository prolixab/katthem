# Utkast – version 0.6.023

Inte publicerad. Sluttid = faktisk lyckad pushtid + exakt 72 timmar.

Rubrik: Frivillig dagsbekräftelse från katthemmets skärm – version 0.6.023

Admin kan separat tillåta att dagens bokade volontärer väljer sitt namn och pass på skärmen och bekräftar att de är där. Lika förnamn får särskiljande bokstäver från efternamnet. Spontana insatser går via QR-kod och personlig inloggning. Funktionen kräver aktiverad närvaromodul och är avstängd från början. Den mäter ingen arbetstid och skapar inga frånvarolistor. Manualen är uppdaterad.

Även tidigare förberedda ändringar ingår: sju dagars skärmschema med veckogräns och QR-kod, rätt e-post mellan katthem, ZIP-nedladdning av kopior, händelser på Anslagstavlan och den valbara närvaromodulen.
