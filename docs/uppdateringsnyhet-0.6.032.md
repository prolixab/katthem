# Utkast – version 0.6.032

Visningssidan kräver nu att superadmin godkänner webbläsaren på katthemmets visningsdator. En kopierad länk räcker inte på en annan dator. Befintliga visningslänkar behöver registreras efter uppdateringen.

QR-koden byts varje minut. Mobilincheckning kräver en aktuell kod och inloggning, och efter giltig skanning finns fem minuter att bekräfta. Mina bokningar visar bekräftelsen och möjlighet att ångra. Bokade volontärer kan fortsatt använda den godkända skärmens namnlista om funktionen är aktiverad. Modulen kan stängas av per katthem.

Uppdateringen innehåller också att volontärer själva kan fylla i födelsedatum när det saknas; admin och SA kan rätta ett sparat datum. Manualerna är uppdaterade.

Inte publicerad. Sammanfattar även opublicerad 0.6.031. Publicera en gemensam nyhet för alla katthem efter lyckad push, med sluttid exakt 72 timmar efter verklig pushtid.
