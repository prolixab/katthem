# Versionsanteckning – version 0.6.037

## Tydligare portalnamn i menyn

Menykolumnen har blivit lite bredare så att Tassportalen får plats på en rad bredvid föreningens logotyp. Logotypen visas också i jämn storlek vid byte av katthem, även när bildfilerna har olika yttermarginaler. Originalfilerna ändras inte. Mobilvyn anpassar logotyp och textstorlek. Manualerna är uppdaterade.

Ingen uppdateringsnyhet ska publiceras för denna version, enligt användarens uttryckliga instruktion. Den befintliga nyheten för 0.6.036 ändras inte.
