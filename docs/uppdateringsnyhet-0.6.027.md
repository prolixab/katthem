# Utkast – version 0.6.027

Städrutiner på passen kan nu ändras permanent eller tillfälligt. Vid tillfällig ändring väljer admin ett datumintervall. De berörda passen märks tydligt och utanför perioden visas de ordinarie rutinerna automatiskt igen. Admin kan även ändra eller ta bort den sparade tillfälliga perioden.

Inte publicerad. Sammanför opublicerade ändringar vid push och publicera en gemensam nyhet med sluttid exakt 72 timmar efter verklig lyckad push.
