# Uppdatering 0.6.027 – rutiner, volontärprofiler och valbar incheckning

Nyhetstext:

Portalen har uppdaterats med en separat visningssida för katthemmet: idag och sex dagar framåt, med tydlig avdelare mellan veckorna och valbar visning av förnamn.

Incheckning finns som en frivillig tillvalsmodul, avstängd från början. Superadmin kan aktivera eller stänga av den per katthem. När den är aktiverad går det att bekräfta bokade pass via ”Jag är här” på visningsskärmen, om admin tillåter det, eller via QR-kod och personlig inloggning. Spontana insatser bekräftas via QR. Ingen arbetstid registreras och saknad bekräftelse räknas inte som frånvaro. Profilen kan visa senaste bekräftelsedatum utan klockslag eller historiklista.

Volontärkortens kontoknappar har samlats i profilen. Superadmin kan återkalla introduktionsgodkännandet utan att rensa checklistan. Introduktionsdelen visas igen tills ett nytt slutligt godkännande ges.

Admin och superadmin kan ändra introduktionschecklistans texter och lägga till punkter för sitt katthem. Befintliga kryss behålls. Nya punkter gäller som standard bara nya och pågående introduktioner.

Städrutinerna på passen kan ändras permanent eller tillfälligt under ett datumintervall. Utanför perioden visas ordinarie rutiner automatiskt igen.

Händelser samlas under Anslagstavlan. Superadmin kan ladda ner säkerhetskopior som ZIP. Visningen av e-post för personer med åtkomst till flera katthem har rättats och manualerna är uppdaterade.

Publiceringsstatus: ännu inte publicerad. Nyheten ska gälla alla katthem med all_shelters=true, published=true och tom targets-lista. Sluttid ska beräknas som faktisk lyckad pushtid + exakt 259200000 ms. Sammanfattar de lokala arbetsutkasten 0.6.020–0.6.026 samt tidigare förberedd ZIP/händelsefunktion; publicera dem inte var för sig.
