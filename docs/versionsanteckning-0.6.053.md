# Versionsanteckning – version 0.6.053

Introduktionschecklistan behåller scrolläge, synlig checklistpunkt, tangentbordsfokus och öppna avsnitt när kryss sparas. Andra pågående checklistval bevaras under statusuppdateringen. Sparmeddelandet ligger separat från hjälptexten för att inte ändra checklistans höjd vid första sparningen.

Ett svar från ett tidigare konto eller katthem ritar inte om den aktuella vyn. Vid misslyckad sparning återställs krysset med ett felmeddelande. Om själva krysset redan sparats men statusuppdateringen misslyckas framgår det utan att ändringen återställs.

Manualen och README är uppdaterade. Uppdateringsnyheten publiceras för alla katthem med sluttid exakt 72 timmar efter lyckad push.

## Utkast till uppdateringsnyhet

Rubrik: Uppdatering 0.6.053 – checklistan behåller din plats

När du kryssar i eller ur introduktionschecklistan ligger sidan nu kvar vid punkten i stället för att hoppa till toppen. Öppna avsnitt och fokus behålls, räknaren uppdateras och du får besked när ändringen är sparad. Manualen är uppdaterad.
