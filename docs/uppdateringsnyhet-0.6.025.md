# Utkast – version 0.6.025

Admin och superadmin kan nu ändra introduktionschecklistans rubriker och texter samt lägga till fler punkter för sitt katthem. Befintliga kryss behålls. Nya punkter gäller som standard bara nya och pågående introduktioner; redan godkända volontärer behöver inte komplettera. Vid nya punkter går det att välja om de gäller alla eller bara nya och pågående introduktioner.

Att återkalla introduktionsgodkännandet rensar inte checklistan.

Inte publicerad. Vid godkänd push ska nyheten publiceras gemensamt för alla katthem och upphöra exakt 72 timmar efter verklig lyckad push. Sammanför vid behov tidigare opublicerade uppdateringar till en gemensam nyhet för den slutliga versionen.

Introduktionsdelen döljs efter slutligt godkännande och visas igen om godkännandet återkallas. Sparade kryss behålls.
